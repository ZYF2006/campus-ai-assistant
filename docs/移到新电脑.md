# 把项目复制到另一台电脑

> 本文档随项目一起复制。目标：把项目文件夹拷到另一台 Windows 电脑后，**双击两个文件**就能跑起来。

## 一、目标电脑必须已经具备的三样东西

| 软件 | 版本要求 | 说明 |
| --- | --- | --- |
| Node.js | >= 20.19（建议 22 LTS） | <https://nodejs.org/zh-cn/download>；装完 `node -v` 能出结果即可 |
| pnpm | 11.x | 不用手动装，`setup.cmd` 会通过 corepack 或 npm 自动安装 |
| MySQL 8 | 8.0.x，端口 3306 | 安装时**记住 root 密码**；装完 `Get-Service MySQL80` 应显示 Running |

另外要求：网络能访问 `registry.npmmirror.com`（安装依赖）和 `dashscope.aliyuncs.com`（百炼模型接口）。

> 没有 MySQL 时，如果有 Docker 也可以：
> ```powershell
> docker run -d --name mysql8 -p 3306:3306 -e MYSQL_ROOT_PASSWORD=123456 mysql:8
> ```

## 二、复制哪些内容（重要）

**正确做法：复制本项目的 zip 包（或整个项目文件夹），但不要复制这些内容：**

- `node_modules/`
- `.pnpm-store/`
- `apps/server/dist/`
- `.vite/`、`.trae/`、`.graphflow/`、`graphflow-out/`
- `*.log`

原因：`node_modules` 是 pnpm 用符号链接/硬链接组织出来的，换机器或换盘符直接拷会失效；这些目录都能由 `setup.cmd` 重新生成。

项目里的 `apps/server/.env` 是**包含真实 API Key 和 MySQL 密码的配置**，需要一起复制（它不会进 git）。`.git` 目录会保留 lab05 分支历史，也一并复制。

## 三、在新电脑上的操作步骤

1. 把项目解压/复制到任意目录，例如 `C:\ai大前端`（路径随便，脚本全部使用相对路径）。
2. 安装 MySQL 8。root 密码有两种处理方式：
   - **方式 A（推荐）**：安装时把 root 密码设成 `123456`，与项目里 `.env` 一致，什么都不用改；
   - **方式 B**：密码随意，装完后编辑 `apps/server/.env`，把 `MYSQL_PASSWORD="123456"` 改成你的密码。
3. 双击项目根目录的 **`setup.cmd`**：自动检查 Node/pnpm/MySQL、安装依赖、建库建表。
4. 双击 **`start.cmd`**：启动前后端，几秒后浏览器自动打开 <http://localhost:5173>。
5. 以后每次用项目：只需双击 `start.cmd`；关掉窗口即停止服务。

## 四、把现有对话记录也带过去（可选）

对话记录存在 MySQL 的 `campus_assistant` 库里，不在项目文件夹里。如果需要带走：

**原电脑导出**（PowerShell）：
```powershell
& 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe' -uroot -p123456 --default-character-set=utf8mb4 campus_assistant > campus_assistant.sql

**新电脑导入**：
```powershell
& 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' -uroot -p123456 --default-character-set=utf8mb4 campus_assistant < campus_assistant.sql
```

如果不导，新电脑上 `setup.cmd` 会建一个空库，聊天记录从零开始。

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| `setup.cmd` 提示找不到 Node.js | 先安装 Node.js 22 LTS，装完重开命令窗口 |
| `pnpm install` 很慢或 403/超时 | 项目 `.npmrc` 已配置 npmmirror 镜像；可重试一次 |
| `db:init` 报 1045 认证失败 | `apps/server/.env` 的 `MYSQL_PASSWORD` 与本机 root 密码不一致 |
| `db:init` 报连接被拒绝 | MySQL 服务没启动：`Get-Service MySQL80`，或端口被占用 |
| 启动后页面打不开 | 后端未起来：查看 `start.cmd` 窗口是否有 `Server running at http://localhost:3000（数据库已就绪）` |
| 端口 3000/5173 被占用 | 上次开发进程没关：结束 node.exe 后重新双击 `start.cmd` |
| 换电脑后页面没有历史 | 会话编号存在浏览器 localStorage，新电脑第一次打开会新建会话，属于预期 |

## 六、原电脑（本机）不受影响

本次只做了三件不影响运行的改动：

1. 新增 `setup.cmd`、`start.cmd`、`tools/setup.ps1`、`tools/start.ps1`（本机也能用）；
2. `.npmrc` 去掉了写死的 `D:/pnpm-store` 路径，改为 pnpm 默认缓存位置（默认也在用户目录，不会进项目仓库）。本机现有的 `node_modules` 不受影响，照常 `pnpm dev`；
3. 清掉了打包用的临时文件。
